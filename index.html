AI · Final Year Project

SEHAT — AI-Powered Medical Assistant

Python · RAG · Neo4j · Groq LLM · BM25

A medical assistant that answers health questions in English and Roman Urdu, grounded entirely in indexed WHO documents rather than model memory.

  • Built a RAG pipeline over indexed WHO medical documents to ground every answer in a verifiable source.
  • Implemented hybrid retrieval — Neo4j vector search fused with BM25 keyword search — for more relevant document recall than either method alone.
  • Served citation-backed answers via Groq LLM, chosen for fast inference on retrieval-heavy queries.

How retrieval works:

StageMethodPurpose
SemanticNeo4j vector searchMeaning-based recall
LexicalBM25Exact-term precision
FusionHybrid rankingBest of both, per query
AnswerGroq LLMFast, citation-backed response
AI / ML

Health & Lifestyle Disease Risk Classifier

Python · pandas · scikit-learn · XGBoost · SMOTE

A supervised classifier predicting whether an individual is "healthy" or "diseased" from lifestyle, demographic, and physiological survey data — ~100,000 rows across 48 features spanning vitals, habits, income, and family history.

  • Cleaned data with column-appropriate strategies: mean/median imputation for numeric fields, probability-weighted sampling for categoricals to preserve true class distribution.
  • Encoded ~15 categorical features and addressed target class imbalance with SMOTE before scaling and training.
  • Compared three models before and after balancing, evaluating with confusion matrices and per-class F1 — not accuracy alone.

Model comparison (accuracy):

ModelBaselineSMOTE + tuned
Logistic Regression83.4%88.2%
XGBoost87.0%87.7%
Random Forest79.4%82.9%

Best config — Logistic Regression on SMOTE-balanced, scaled data — reached 88.2% accuracy (F1: 0.92 healthy / 0.80 diseased).
